# 👨‍💻 Esperienza professionale

### Junior Full Stack Developer – Kostelia S.R.L.
📅 Ottobre 2025 – Presente

Sviluppo e manutenzione di applicazioni web gestionali dedicate alla gestione dei processi logistici e delle attività di magazzino, con particolare attenzione ai sistemi WMS (Warehouse Management System).

Lavoro su un sistema WMS multi-cliente, partecipando alle diverse fasi del ciclo di sviluppo: dall'analisi dei requisiti e della logica applicativa fino all'implementazione, al testing e al debugging.

**Principali attività e progetti:**

- Sviluppo e manutenzione di funzionalità frontend e backend utilizzando C#, .NET 10, Blazor e MudBlazor.
- Progettazione e implementazione di logiche applicative per la gestione dei flussi di magazzino.
- Realizzazione di diagrammi di flusso per analizzare e strutturare i processi prima dello sviluppo.
- Sviluppo di applicazioni per terminali barcode Zebra, dedicate alla gestione dell'ingresso merci, alla movimentazione delle giacenze e alle attività di picking e preparazione delle spedizioni.
- Collaborazione allo sviluppo di un'applicazione per la gestione del confezionamento di dispositivi Telepass.
- Gestione e interrogazione di database PostgreSQL tramite SQL ed Entity Framework Core.
- Integrazione e utilizzo di API REST e servizi esterni.
- Attività di testing, debugging e verifica del corretto funzionamento delle funzionalità sviluppate.
- Utilizzo di Git e GitHub per la gestione del codice e collaborazione nei flussi di sviluppo.

**Tecnologie utilizzate:** C#, .NET 10, ASP.NET Core, Blazor, MudBlazor, Entity Framework Core, PostgreSQL, SQL, REST API, Git, GitHub.
